Privacy / Gizlilik

English

This Link Bio does not use advertising cookies. A manually selected TR/EN language preference may be stored in your browser’s local storage. An automatic language result may be kept only for the current browser session.

When there is no URL or saved language preference, the browser requests ipapi.is to identify the country from the connection IP. This site uses only the returned two-letter country code: Türkiye selects Turkish; every other country selects English. This site does not store the IP address or precise location. The provider necessarily receives the connection IP. If the request fails or is rate-limited, the browser language is used.

The site uses lightweight anonymous aggregate counters for page views, traffic-source categories, selected language and social-button clicks. The counter service is public/no-auth, so figures can be manipulated and should be treated as directional rather than tamper-proof.

No social-media password, account credential, OAuth token or message content is collected by this Link Bio.

Türkçe

Bu Link Bio reklam çerezi kullanmaz. Manuel seçilen TR/EN dil tercihi tarayıcınızın yerel depolamasında saklanabilir. Otomatik dil sonucu yalnızca mevcut tarayıcı oturumu boyunca tutulabilir.

URL’de veya cihazda kayıtlı bir dil tercihi yoksa tarayıcı, bağlantı IP’sinden ülkeyi belirlemek için ipapi.is hizmetine istek gönderir. Bu site yalnızca dönen iki harfli ülke kodunu kullanır: Türkiye için Türkçe, diğer ülkeler için İngilizce seçilir. Bu site IP adresini veya kesin konumu saklamaz. Hizmet sağlayıcı bağlantı gereği IP adresini görür. İstek başarısız olursa veya sınıra takılırsa tarayıcı dili kullanılır.

Sayfa görüntüleme, trafik kaynağı kategorisi, seçilen dil ve sosyal medya buton tıklamaları için hafif anonim toplu sayaçlar kullanılır. Sayaç servisi public/no-auth olduğu için rakamlar manipüle edilebilir; bu veriler değiştirilemez denetim kaydı değil, yön gösteren istatistiklerdir.

Bu Link Bio sosyal medya parolası, hesap giriş bilgisi, OAuth tokenı veya mesaj içeriği toplamaz.
